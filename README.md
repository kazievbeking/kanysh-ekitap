# Қаныш және ғылыми майдан

Қазақ тіліндегі анимациялық интерактивті кітап. React, TypeScript және Vite негізінде жасалған; сервер мен дерекқор қажет емес.

Жарияланған сайт: https://kazievbeking.github.io/kanysh-ekitap/

## Іске қосу

Node.js 22 немесе одан жаңа үйлесімді нұсқасын орнатыңыз.

```sh
npm ci
npm run dev
```

Терминалда көрсетілген жергілікті сілтемені ашыңыз. Жинау және тексеру:

```sh
npm test
npm run build
npm run preview
```

Осы компьютерде Node жүйелік PATH ішінде болмағандықтан, жұмыс барысында `.tools/node.exe` көшірмесі қолданылды. Қажет болса PowerShell ішінде:

```powershell
$env:Path = (Join-Path $PWD '.tools') + ';' + $env:Path
& .\.tools\node.exe .tools/package/bin/npm-cli.js run dev
```

`.tools` — тек жергілікті көмекші орта; GitHub-қа жүктелмейді.

## Мүмкіндіктер

- Жабық мұқаба, ашылу ауысуы, кітаптың таныстыру беті және мазмұны.
- Үш бөлім, 14 анимациялық көрініс және аудиоға сәйкес ауысатын жоспарлар.
- Негізгі көрсетілімде мәтін панелі жоқ. Түпнұсқа мәтін деректерде сақталған және тапсырмаларда үзінді ретінде көрсетіледі.
- Мұқаба портреті және тарихи көріністердің көркем иллюстрациялары; жаңа бөлімге аурухана мен әуежай суреттері қосылды.
- Нақты үш MP3, көрініспен шектелген ойнату, кідірту, дыбыс деңгейі және аудио уақытын сақтау.
- Оқиға ішіндегі бес ойын: сүйреу, басып таңдау, пернетақта, кеңес және қайталау.
- Ойын кезінде дыбыс пен сурет қозғалысы тоқтайды; шешімнен кейін келесі көріністен жалғасады.
- Оқу барысы, аяқталған ойындар, соңғы көрініс, дыбыс пен қозғалыс баптаулары localStorage ішінде сақталады.
- «Қаныш әлемі» энциклопедиясы: үш бөлім, толық мәтіндер, бет нөмірлері және бөлім ішіндегі іздеу.
- Телефон мен компьютерге бейімделген, толық енді анимациялық сахна. Құрылғының `prefers-reduced-motion` баптауы ескеріледі.

Көріністерде жел, жарық, құстар, жазудың пайда болуы, сахна пердесі, хат пен билет, сағат, пойыз, дөңгелектер және бу қабаттары қозғалады. Бұл - иллюстрация мен SVG/CSS қабаттарына негізделген сахналық анимация; толық кейіпкерлік мимика немесе дайын бейнефильм емес.

## Анимацияның құрылымы

`src/data/storyboards.ts` әр көріністегі жоспарлардың басталу уақытын, суретін және қозғалыс түрін сипаттайды. `at` уақыты сол көріністің аудио басынан секундпен есептеледі. Кітаптағы оқиға немесе диктор мәтіні өзгертілмейді.

`AnimatedStory.tsx` нақты аудио уақытын оқып, камераны және кадр ауысуын синхрондайды. `FilmLayers.tsx` жеке қозғалатын қабаттарды, `animated-story.css` олардың қозғалысын анықтайды. Аудионы кідірту, аудионы алға-артқа жылжыту, тапсырма ашу және бетті қайта жүктеу тиісті анимациялық кадрды қалпына келтіреді. Қозғалысты азайту қосылса, қозғалыс қабаттары өшеді; қажетті жоспарлар дыбысқа сәйкес көрсетіледі.

Қосымша суреттер кіріктірілген image_gen құралымен жасалды: `public/images/heritage.webp`, `manuscript.webp`, `warning.webp`, `station.webp`. Олардың промпттары `docs/animation-image-prompts.json` ішінде сақталған.

## Мәтін мен суретті ауыстыру

Әр бөлімде екі тапсырма бар. Бірінші бөлім: «Тарихи сәтті қалпына келтір» және «Ғылыми топты құрастыр». Екінші бөлім: «Оқиғалар тізбегі» және «Сапар бағытын құрастыр». Тапсырмалар көріністердің соңында автоматты түрде ашылады. Оқу экранындағы «Тапсырмалар» батырмасынан кез келгенін қайта орындауға болады; бұл жағдайда әңгіме сол тоқтаған уақытынан жалғасады. Орындалған тапсырмалар браузерде сақталады.

Бөлімнің JSON файлында көріністің `paragraphs` тізімін өңдеңіз. Әр тізім элементі — бір абзац. Көріністердің `id` мәндерін өзгерту бұрын сақталған аудио уақыттары мен байланыстарға әсер етеді.

`public/images/` ішіне жаңа суретті салыңыз. Көріністегі `image` өрісіне WebP файлының кеңейтімсіз атауын жазыңыз. Мысалы, `"image": "academy"` — `public/images/academy.webp`. Мұқаба `portrait.webp` файлын пайдаланады. Тарихи тұлғаның бейнесі үшін сол портреттік референсті қолданыңыз. Иллюстрацияға арналған промпттар `docs/image-prompts.json` ішінде сақталған.

Қаріптер жергілікті беріледі; іске қосылған сайт Google Fonts-қа сұрау жібермейді.

## Аудионы жаңарту және синхрондау

MP3 файлдарын `public/audio/` ішіне салыңыз. `audio-manifest.json` ішіндегі әр көрініс үшін `file`, `start`, `end` мәндерін көрсетіңіз. Уақыттар секундпен, бастапқы тұтас файлға қатысты беріледі:

```json
{"file":"audio/chapter-1.mp3","start":0,"end":12.5}
```

Бұл — пішім мысалы; нақты жобаның уақыттарын manifest файлынан қараңыз. Көріністің `end` мәні келесі көріністің `start` мәніне тең болуы керек. Жеке MP3 берілсе, `start: 0`, `end` — сол файлдың нақты ұзақтығы болады. Көрініске байланыс берілмесе, аудио батырмасы өшеді, мәтін мен ойын жұмысын жалғастырады.

Аудио ауысқанда, бөлімнен шыққанда немесе ойын ашылғанда ескі дыбыс кідіреді. Ойынның алдында тұрған көріністегі `gameAfter` ойын идентификаторын көрсетеді. Дұрыс шешім келесі көріністің басынан жалғастырады. Ойын аудиосы жоқ.

`materials/audio-*-timings.json` — жергілікті тану құралының техникалық нәтижесі. Бұл кітап мәтінінің дереккөзі емес. Мәтінді осы тану нәтижесімен ауыстырмаңыз. Аудио шекараларын өзгертсеңіз, екі бөлімнің толық сценарийін тексеріңіз.

## Фондық музыка

Жоғарғы мәзірдегі нота батырмасы фондық музыканы қосады және өшіреді. Оның жанындағы төмен бағытталған белгі музыка баптауларын, жеке дыбыс деңгейін және авторлық мәліметтерді ашады. Әуен әдепкіде өшірулі; ойнату оқырманның әрекетінен кейін басталады. Дыбыс деңгейі осы браузерде сақталады.

Диктор сөйлегенде музыка деңгейі таңдалған мәннің 22 пайызына дейін біртіндеп төмендейді. Ойын, баптау терезесі немесе энциклопедия ашылғанда, сондай-ақ шолғыш беті жасырылғанда фон кідіреді. Қайта жалғасқанда музыка тоқтаған жерінен жүреді. Бөлім мәтіндерінің MP3 файлдары өзгертілген жоқ.

Композиция: **Meditation Impromptu 01**, авторы **Kevin MacLeod (incompetech.com)**. Лицензиясы: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). [Автордың ресми парағы](https://incompetech.com/music/royalty-free/index.html?Search=Search&isrc=USUAN1100163).

Файл `public/audio/music/meditation-impromptu-01.mp3` ішінде жергілікті сақталған. Ұзақтығы — 212.82 секунд; қайта ойнатылады. Түпнұсқа өзгертілген жоқ. Дереккөз және авторлық белгі `public/audio/music/LICENSE.txt` ішінде және сайттағы музыка баптауларында берілген. Оларды жарияланған нұсқада сақтаңыз.

Музыканы ауыстыру үшін осы қалтаға жаңа файлды қосып, `src/data/music.ts` деректерін және лицензия мәліметін жаңартыңыз. Қолдануға рұқсаты бар файлды пайдаланыңыз. Бұл әуен қазақтың дәстүрлі музыкасы немесе тарихи жазба ретінде ұсынылмайды.

## Жаңа бөлім қосу

1. `src/data/` ішінде көріністері бар JSON жасаңыз. Әр көріністе бірегей `id`, `title`, `image`, `caption`, `label`, `paragraphs` болсын.
2. `book.ts` ішіндегі `chapters` тізіміне жаңа бөлімді тіркеңіз.
3. Суреттер мен аудионы тиісті public қалталарына қосыңыз; manifest-ке көріністердің нақты уақыттарын жазыңыз.
4. Жаңа ойын қажет болса, `games.ts` деректерін және `Games.tsx` ойын компонентін кеңейтіңіз. Бірегей тұрақты идентификатор қолданыңыз.

Энциклопедия «Қаныш әлемі кітапша.docx» жинағы бойынша толықтырылды: Қаныштың тұжырымды ойлары, ғалымдардың пікірлері, мақал-мәтелдер.

## GitHub Pages

1. GitHub-та бос репозиторий жасаңыз немесе бар репозиторийді таңдаңыз.
2. Осы жобаны `main` тармағына жүктеңіз. `node_modules`, `.tools`, `.cache`, `dist` жүктелмеуі керек.
3. Репозиторийде **Settings → Pages → Build and deployment → Source → GitHub Actions** таңдаңыз.
4. `main` тармағына push жасаңыз немесе **Actions** ішінен жариялау тапсырмасын қолмен іске қосыңыз.
5. Workflow тесттерді орындап, жобаны жинап, `dist` қалтасын жариялайды. Репозиторий атауы автоматты түрде `VITE_BASE_PATH` арқылы беріледі; `USERNAME.github.io` репозиторийі үшін `/` қолданылады.

Жергілікті жинау әдепкіде салыстырмалы `./` жолын пайдаланады. Аудио мен сурет сілтемелері `import.meta.env.BASE_URL` арқылы жасалады. Навигация `#/read/academy/0` тәрізді hash жолдарын пайдаланады, сондықтан бет жаңарғанда серверден бөлек маршрут сұралмайды.

Мәтін, аудио немесе суреттерді кейін жаңарту үшін файлдарды өзгертіп, тест пен жинауды орындап, `main` тармағына push жасаңыз. Workflow қайта жариялайды. Әр оқырманның прогресі оның өз браузерінде сақталады.

Қолданыстағы аккаунт немесе репозиторий байланысы берілмеген жағдайда GitHub-қа жариялау орындалмайды. Бұл жағдайда репозиторий сілтемесі және оған жазу мүмкіндігі керек. Токендерді кодқа немесе чатқа қоспаңыз.

## Үш бөлімнің реті

1. «Академияның ашылуы» — 117–119-беттер.
2. «Мен болмайын, сен бол!» — 284–285-беттер.
3. «Қашқын академик» — 289–291-беттер.

Жаңа бөлімнің түпнұсқасы: `materials/chapter-3-source.pdf`, қалыпқа келтірілген мәтін: `materials/chapter-3-extracted.txt`, аудиосы: `public/audio/chapter-3.mp3`. Көрініс шекаралары MP3-тегі сөйлемдер арасындағы үзілістерге қойылды. Автоматты танылған мәтін тек уақытты анықтау үшін пайдаланылады; кітап мәтінін алмастырмайды.

Қол қимылдары — шағын WebGL-деформациялар; қолдау болмаса бастапқы сурет көрсетіледі. Бүкіл кадрдың CSS-кластары сәндік қабаттардан бөлінген, сондықтан иллюстрациялар толық сахнаны жабады.
