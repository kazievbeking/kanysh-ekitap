# «Қаныш және ғылыми майдан» интерактивті кітап-сайтын әзірлеу

## Жоба туралы

Мен «Қаныш және ғылыми майдан» кітабының берілген үзінділері негізінде қазақ тіліндегі интерактивті кітап-сайт жасадым. Бұл жобада кітап мәтінін, аудио, көркем иллюстрациялар мен танымдық тапсырмаларды бір ортаға біріктірдім. Оқырманға мәтінді оқумен қатар тыңдауға, оқиғаға байланысты суреттерді көруге және тапсырмалар арқылы оқығанын ой елегінен өткізуге мүмкіндік беруді мақсат еттім.

Жобаның негізгі кейіпкері — Қаныш Сәтбаев. Мен оның ғылым жолындағы қызметін және өміріндегі қиын кезеңді кітапта берілген баяндау арқылы таныстыруды көздедім. Кітаптың авторлық мәтінін өзім жазған мәтіннен ажыратып, тарихи мазмұнды еркін өзгертуге жол бермеуге тырыстым. Менің жұмысым — берілген әдеби материалды интерактивті цифрлық ортада ұсыну.

Сайттың интерфейсін, батырмаларын, ойын нұсқаулықтарын, кеңестері мен хабарламаларын қазақ тілінде дайындадым. Әзірлеу барысында кодты құрастыру және иллюстрацияларды дайындау үшін жасанды интеллект құралдарын да қолдандым.

## 1. Жобаның мақсаты мен міндеттерін анықтау

Алдымен жобаның негізгі мақсатын белгіледім: кітап мазмұнын оқырманға оқуға, тыңдауға және ойлануға ыңғайлы түрде жеткізу. Оқырманның назарын тек мәтінде ұстаудың орнына, оқиғаға сәйкес иллюстрациялар мен тапсырмаларды да пайдаландым.

Осы мақсатқа жету үшін мына міндеттерді қойдым:

- кітаптың мұқабасы мен мазмұнына сай көркем безендіру жасау;
- берілген екі бөлімнің мәтінін толық енгізу;
- аудионы мағыналық көріністермен байланыстыру;
- әр бөлімге екі интерактивті тапсырмадан қосу;
- ойын ашылғанда әңгімені кідіртіп, тапсырмадан кейін жалғастыру;
- оқу барысын браузерде сақтау;
- компьютер мен телефон экранына арналған орналасуды дайындау;
- жобаны кейін GitHub Pages арқылы жариялауға бейімдеу.

Қазіргі нұсқада екі бөлім, тоғыз көрініс және төрт интерактивті тапсырма бар.

## 2. Бастапқы материалдарды зерттеу

Жұмысты кітапқа қатысты материалдарды қараудан бастадым. Дереккөз ретінде «Тексты из книг.pdf» файлын, кітаптың мұқабасын, басылым мәліметтері жазылған ішкі бетті және екі MP3 аудиофайлын пайдаландым.

Басылым мәліметтерін ішкі беттен алдым: С. Керімбай, Ә. Нәби, «Қаныш және ғылыми майдан», Алматы, «Отбасы» баспа үйі, 2024 жыл, 456 бет. Сайттағы таныстыру мәтінін осы мәліметтерге сүйеніп дайындадым.

Бірінші бөлім үшін 117–119-беттерге жататын мәтінді, екінші бөлім үшін 289–291-беттерге жататын мәтінді қолдандым. Бірінші бөлімді «Академияның ашылуы», екіншісін «Қашқын академик» атауларымен ұсындым.

PDF-ті тексергенде, оның ішінде мәтін терілген түрде берілгенін анықтадым. Сондықтан мәтінді фотосуреттен қайта танытудың орнына PDF-тен тікелей шығарып алдым. PDF беттерін суретке айналдырып та қарап, екі бөліктің орналасуы мен мәтіннің жалғасуын салыстырдым. Бұл жұмысқа Ghostscript құралын пайдаландым.

Мәтіннің техникалық жол тасымалдарын біріктірдім және дыбыстауға арналған `[thoughtful]` белгісін оқылатын нұсқадан алып тастадым. Күмәнді сөздерді баспа нұсқасымен салыстырмай өз бетімше түзеткен жоқпын. Нақтылауды қажет ететін тұстарды жеке ескертпелер файлына жаздым.

Бірінші бөлімдегі жеке тақырыптардың шекаралары PDF ішінде көрсетілмегендіктен, қолда бар бірінші бөліктің мәтінін түгел қолдандым. «Кенесарының шөбересі» тақырыбының мәтінін жобаға қосқан жоқпын.

## 3. Технологияларды таңдау және жобаны ұйымдастыру

Сайтты React, TypeScript және Vite негізінде жасадым. React арқылы интерфейсті жеке компоненттерге бөлдім. TypeScript арқылы компоненттерге берілетін деректердің түрлерін сипаттап, сәйкессіздіктерді жинау кезінде анықтауға мүмкіндік жасадым. Vite құралын әзірлеу сервері мен дайын сайтты жинау үшін қолдандым.

Безендіруді CSS арқылы орындадым. Батырмалардағы кітап, дыбыс, пойыз және кеңес белгілері үшін Lucide белгішелерін пайдаландым. Мәтіннің оқылуын жақсарту үшін Noto Sans және Noto Serif қаріптерін таңдадым. Қаріп файлдарын жоба ішінде сақтап, сайт ашылғанда сыртқы қаріп қызметіне тәуелділікті азайттым.

Кодты бір файлға жинамай, міндетіне қарай бөлдім:

- `BookShell` — сайттың ортақ қабығы мен жоғарғы мәзірі;
- `Cover` — жабық кітап мұқабасы;
- `Home` — таныстыру беті мен мазмұны;
- `Reader` — көріністерді оқу және олардың арасында ауысу;
- `AudioControls` — диктор аудиосын басқару;
- `BackgroundMusic` — фондық музыканы басқару;
- `Games` және `ExtraGames` — интерактивті тапсырмалар;
- `Modal` — тапсырмалар мен баптауларды бөлек терезеде көрсету;
- `Encyclopedia` — энциклопедия беті.

Мәтін, көрініс сипаттамалары, тапсырма деректері және аудио байланыстарын интерфейс кодынан бөлек сақтадым. Осылайша кейін мәтінді жаңарту немесе жаңа бөлім қосу жеңілдейді.

## 4. Кітапқа ұқсас дизайн жасау

Сайттың бастапқы экранын жабық кітап түрінде жасадым. Мұқабаға берілген фотосуреттегі Қаныш Сәтбаевтың портретін негіз етіп алдым. Қара-ақ бейнені, төменгі бөліктегі қою реңкті, мыс түстес «ҚАНЫШ» атауын және ашық түсті қалған жазуды сақтауға тырыстым.

Атауларды суретке жазып қоймай, HTML мәтінімен орналастырдым. Бұл жазуды әртүрлі экранға бейімдеуге мүмкіндік берді. Бастапқы фотосуреттегі кілем мен кітаптан тыс заттарды сайт дизайнына енгізген жоқпын.

«Кітапты ашу» батырмасын басқанда мұқабаның ашылу ауысуын қостым. Одан кейін оқырман кітаптың таныстыру беті мен мазмұнына өтеді. Ішкі беттер үшін жылы қағаз түстерін, қоңыр және жасыл реңктерді, жұқа сызықтар мен ұстамды көлеңкелерді таңдадым.

Компьютер экранына қос бетті орналасу дайындадым. Оқу кезінде бір жақта иллюстрация, екінші жақта мәтін панелі орналасады. Телефонға арналған нұсқада элементтерді бір бағанға орналастырдым. Мәтін панелін ашу және жасыру мүмкіндігін қостым.

Қозғалысты азайтуды қалайтын оқырмандар үшін арнайы баптау жасадым. Сонымен қатар құрылғының `prefers-reduced-motion` баптауын ескердім.

## 5. Мәтінді мағыналық көріністерге бөлу

Бірінші бөлімді төрт көрініске бөлдім:

1. «Ұлы арманның бастауы».
2. «Ғылымға бастар жол».
3. «Бір мақсатқа біріккен ғалымдар».
4. «Академияның ашылуы».

Екінші бөлімді бес көрініске бөлдім:

1. «Сын сағат».
2. «Ескерту және әріптестің көмегі».
3. «Алматыны қимай аттану».
4. «Алаңға толы сапар».
5. «Әріптестердің қолдауы».

Көрініс атауларын навигацияға ыңғайлы болу үшін дайындадым. Оларды кітаптан сөзбе-сөз алынған тақырыптар ретінде ұсынған жоқпын. Ал оқу панеліндегі негізгі мәтінді берілген PDF-тен алдым.

Әр көрініске жеке идентификатор, атау, иллюстрация, қысқаша сипаттама және мәтін байланыстырдым. Бірінші бөлімді `academy.json`, екінші бөлімді `fugitive.json` файлына сақтадым. Оқырманға алдыңғы және келесі көрініске ауысу мүмкіндігін қостым.

## 6. Иллюстрациялар дайындау

Иллюстрацияларды дайындағанда Қаныш Сәтбаевтың келбетін бірізді сақтауға назар аудардым. Алдымен кітап мұқабасына негізделген портреттік референс жасадым. Кейін басқа көріністерді дайындау кезінде сол портретті қолдандым.

Жасанды интеллект көмегімен мұқаба портретін және алты көркем иллюстрация дайындадым: театр маңы, ғылыми жұмыс ортасы, ашылу салтанаты, жолға шығар алдындағы кеш, пойыз сапары және әріптестердің қарсы алуы.

Суреттерде тарихи кезеңге сәйкес киім, интерьер, көлік пен тұрмыстық заттарды көрсетуге тырыстым. Өзге адамдарды нақты тарихи тұлғалардың дәл портреттері ретінде емес, шартты көркем бейнелер ретінде бердім. Сайтта иллюстрациялардың көркемдік сипатта екенін белгіледім.

Дайын суреттерді сайтқа ыңғайлы WebP пішіміне ауыстырдым. Оларды `public/images` қалтасына сақтадым. Генерацияға қолданылған сипаттамаларды `docs/image-prompts.json` файлына жаздым.

Суреттерге баяу жақындау және жұмсақ ауысу әсерлерін қостым. Қозғалыстың ұзақтығын аудио үзіндінің ұзақтығымен байланыстырдым. Бұл тәсіл толық кейіпкерлік анимация емес, иллюстрацияға берілген камера қозғалысы екенін ескердім.

## 7. Аудионы қосу және көріністермен байланыстыру

Дыбыстау үшін екі дайын MP3 файлын пайдаландым. Оларды бірінші және екінші бөлімдерге сәйкестендіріп, `chapter-1.mp3` және `chapter-2.mp3` атауларымен сақтадым. Жаңа қысқартылған дикторлық мәтін жазған жоқпын.

Бірінші аудиофайлдың ұзақтығын шамамен 3 минут 58 секунд, екіншісін 4 минут 30 секунд деп анықтадым. Аудионы көріністермен байланыстыру үшін `audio-manifest.json` файлын жасадым. Онда әр көріністің аудиофайлы, басталу және аяқталу уақыты көрсетілді.

Уақыт шекараларын анықтауда жергілікті автоматты сөйлеуді тану құралын қолдандым. Сөйлем басталуы мен олардың арасындағы үзілістерге сүйеніп, үзінділердің шекараларын белгіледім. Тану нәтижесіндегі қате сөздерді кітап мәтініне көшірген жоқпын: оларды тек уақытты анықтауға көмекші материал ретінде пайдаландым.

Ойнату, кідірту, дыбыс деңгейі және ағымдағы уақыт көрсеткіштерін қостым. Көрініс немесе бөлім ауысқанда алдыңғы диктор аудиосын тоқтатуды ұйымдастырдым. Ойын ашылғанда дыбысты кідіртіп, дұрыс шешімнен кейін келесі көріністен жалғастыруды жасадым.

Оқу экранындағы тапсырмалар мәзірінен ойын ашылса, оны аяқтағаннан кейін оқырманды сол тұрған көрінісіне қайтардым. Бұған дейін аудио ойналып тұрған болса, ол тоқтаған уақытынан жалғасады.

## 8. Төрт интерактивті тапсырма жасау

Әр бөлімге екі тапсырмадан қостым. Тапсырмаларды оқырманға кітап үзіндісін қайта қарап, шешім қабылдауға мүмкіндік беретін әрекет ретінде ұйымдастырдым.

| Бөлім | Тапсырма | Оқырманның әрекеті |
| --- | --- | --- |
| Академияның ашылуы | Тарихи сәтті қалпына келтір | Ашылудың жылын, күнін және өткен орнын таңдап, сөйлем құрастырады. |
| Академияның ашылуы | Ғылыми топты құрастыр | Ғалымдарды ғылым салаларымен сәйкестендіреді. |
| Қашқын академик | Оқиғалар тізбегі | Хабар алу, билет алу, дайындалу және пойызға отыру әрекеттерін реттейді. |
| Қашқын академик | Сапар бағытын құрастыр | Мәтінде аталған қалаларды сапар ретімен таңдайды. |

Бірінші қосымша тапсырмада кітап үзіндісіне сүйеніп, 1946 жылды, 1 шілдені және Абай атындағы Опера және балет театрын таңдауды ұсындым. Таңдалған жауаптардан тұтас сөйлем құрастырдым.

Ғалымдар туралы тапсырмада Әлкей Марғұлан — тарих, Мұхтар Әуезов — әдебиет, Ахмет Жұбанов — өнертану сәйкестіктерін қолдандым. Бұл сәйкестіктердің бәрі PDF ішінде толық жазылмағандықтан, олардың жоба тапсырмасынан алынғанын бөлек белгіледім.

Оқиғалар тізбегінде себеп-салдар байланысын пайдалануды ұсындым. Билет хабардан кейін алынады, дайындық билеттен кейін аяқталады, пойызға дайындықтан соң отырады деген шарттарды ойынның логикалық моделі ретінде бердім. Оларды кітаптан алынған сөзбе-сөз дерек деп көрсеткен жоқпын.

Сапар тапсырмасында Алматы → Қызылорда → Орал → Қазан → Мәскеу ретін қолдандым. Қалаларды мәтінде аталуына сүйеніп таңдадым. Бұл сызбаны нақты географиялық карта немесе барлық станциялардың толық тізімі ретінде ұсынған жоқпын.

Барлық тапсырмада кітап үзіндісін, кеңес және қайта орындау мүмкіндігін қостым. Қате жауап үшін ұпай шегеру немесе әрекет санын шектеу енгізген жоқпын. Дұрыс жауаптан кейін түсіндірме мен «Әңгімені жалғастыру» батырмасын көрсеттім.

Карточкаларды сүйреумен қатар, батырмамен таңдау және орын ауыстыру тәсілдерін жасадым. Пернетақтамен басқаруға арналған стандартты батырмаларды пайдаландым. «Тапсырмалар» мәзірі арқылы бұрын орындалған ойынға қайта кіруге мүмкіндік бердім.

## 9. Фондық музыканы қосу

Жобаға тыныш фортепиано әуенін қостым. Ол үшін Kevin MacLeod авторының «Meditation Impromptu 01» композициясын автордың ресми сайтынан жүктедім. Әуенді кітап оқуына жұмсақ фон ретінде таңдадым; оны тарихи жазба немесе қазақтың дәстүрлі музыкасы ретінде ұсынған жоқпын.

Автордың ресми парағында көрсетілген CC BY 4.0 лицензиясына сүйеніп, авторлық мәлімет пен лицензия сілтемесін сайттағы музыка баптауларына және жоба файлдарына қостым. Музыканың түпнұсқа файлын өзгертпей сақтадым.

Музыканы оқырман өзі қосатын етіп жасадым. Жоғарғы мәзірге нота белгісін және жеке дыбыс деңгейін басқаруды қостым. Диктор сөйлегенде фондық музыканы таңдалған деңгейдің 22 пайызына дейін біртіндеп бәсеңдеттім. Ойын ашылғанда, баптау терезесі көрсетілгенде немесе шолғыш беті жасырылғанда музыканы кідірттім.

Бұл арқылы диктор дауысы мен фондық әуенді бөлек басқаруға мүмкіндік бердім. Оқырман музыканы толық өшіріп, тек кітап аудиосын тыңдай алады.

## 10. Оқу барысын сақтау

Сайтқа тіркелу жүйесін немесе дерекқор қоспадым. Оқу барысын `localStorage` арқылы әр оқырманның өз браузерінде сақтадым.

Сақталатын мәліметтерге соңғы бөлім мен көріністі, аяқталған тапсырмаларды, оқылған бөлімдерді, аудиода тоқтаған уақытты, дыбыс деңгейін және қозғалыс баптауын енгіздім. Фондық музыканың дыбыс деңгейін де жеке сақтадым.

Оқырман бетті жаңартқанда оқу барысын қалпына келтіруді ұйымдастырдым. «Басынан бастау» әрекетін қостым және прогресті тазаламас бұрын растау сұрағын көрсеттім. Браузерде сақтау мүмкіндігі бұғатталса немесе сақталған дерек бүлінсе, қолданба жұмысын жалғастыруы үшін тексерулер енгіздім.

## 11. Энциклопедия және жобаны кеңейту

Энциклопедияны жеке бет ретінде жасадым. Қазіргі нұсқада оған мақала, термин немесе мысал қосқан жоқпын. Онда тек бет атауы мен кері қайту навигациясын қалдырдым.

Жобаны кейін толықтыруға ыңғайлы етіп ұйымдастырдым. Жаңа бөлімнің мәтіні мен көріністерін деректер файлына қосуға, суреттер мен аудионы тиісті қалталарға орналастыруға болады. Әр тапсырмаға тұрақты идентификатор бердім. Бұл орындалған тапсырмаларды сақтау мен оларды көріністерге байланыстыруды жеңілдетті.

## 12. Жобаны тексеру және қателерді түзету

Жобаның TypeScript тексеруін және Vite арқылы өндірістік жинауын орындадым. Қате анықталған тұстарды түзеткеннен кейін қолданбаны қайта жинадым.

Vitest және Testing Library арқылы автоматты тесттер дайындадым. Қазіргі нұсқада 14 тест сәтті өтті. Осы тесттер арқылы екі бөлімнен толық өтуді, төрт тапсырманың жұмысын, қате жауаптан кейін қайталауды, аудионың кідіруі мен жалғасуын, оқу барысының сақталуын және фондық музыканың басқарылуын тексердім.

PDF-тен алынған мәтін мен көріністерге бөлінген мәтінді автоматты түрде салыстырдым. Аудио шекараларының бір-біріне жалғасатынын, нақты MP3 ұзақтығынан аспайтынын және барлық сурет пен аудио файлының бар екенін тексердім.

Сынақ кезінде сайттың ақ экран болып ашылу мәселесін анықтадым. Жергілікті әзірлеу сервері қолданбаның бос JavaScript модулін беріп тұрғанын тексеріп, серверді дайын жинақты көрсететін режимге ауыстырдым. Одан кейін дайын JavaScript файлының жүктелуін және кітап мұқабасының DOM ортасында көрсетілуін тексердім.

Тест нәтижелерінің шегін де ескердім: автоматты сынақтарда браузердің аудио әрекеттері үлгіленген. Сондықтан олар нақты құрылғыда дыбысты тыңдау мен сыртқы көріністі тексеруді толық алмастырмайды. Телефондағы орналасуды және аудио шекараларын нақты браузерде қосымша тексеру қажет.

## 13. Іске қосу және жариялауға дайындау

Жобаны жергілікті ортада іске қосу үшін мына командаларды дайындадым:

```sh
npm ci
npm run dev
```

Тест жүргізу, дайын нұсқаны жинау және оны алдын ала көру үшін келесі командаларды қолдандым:

```sh
npm test
npm run build
npm run preview
```

GitHub Pages үшін hash негізіндегі навигацияны таңдадым. Бөлімдердің мекенжайы `#/read/academy/0` тәрізді болады. Бұл статикалық хостингте бетті жаңартқанда бөлек серверлік маршрутты талап етпеуге мүмкіндік береді.

Репозиторийдің атауына сәйкес базалық жолды орнататын баптауды және GitHub Actions тапсырмасын дайындадым. Жариялау тапсырмасы тәуелділіктерді орнатады, тесттерді жүргізеді, жобаны жинайды және дайын файлдарды GitHub Pages-ке жіберуге арналған.

Қазіргі кезде жоба жергілікті ортада жұмыс істейді. GitHub-тағы аккаунт пен репозиторий байланысы берілмегендіктен, интернетке жариялау әлі орындалған жоқ. Сондықтан жобаны жариялауға дайындадым деп көрсетемін, бірақ оны қазірдің өзінде жалпыға қолжетімді сайт ретінде сипаттамаймын.

## 14. Қол жеткізген нәтиже және келесі жұмыс

Осы жұмыс барысында берілген кітап үзінділерін біртұтас интерактивті кітап-сайтқа біріктірдім. Екі бөлімнің мәтінін сақтап, оларды тоғыз көрініспен, екі аудиофайлмен, жеті иллюстрациямен және төрт тапсырмамен байланыстырдым. Оқу барысын сақтау, фондық музыканы басқару және тапсырмаларға қайта оралу мүмкіндіктерін қостым.

Одан кейін GitHub репозиторийіне орналастырып, GitHub Pages арқылы жариялауға болады. Энциклопедияны тек тексерілген материалдар дайын болғанда толықтыруды көздеймін.
