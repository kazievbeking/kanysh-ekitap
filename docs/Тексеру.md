# Тексеру нәтижесі

## Орындаған тексерулер

- TypeScript тексеруі және Vite өндірістік жинауы сәтті орындалды.
- Автоматты компоненттік тесттер екі бөлімнің көріністері арқылы толық өтуін тексереді.
- Бірінші ойынның қате жауабы, дұрыс сәйкестіктері, дыбысты тоқтатуы және келесі көріністен жалғастыруы тексерілді.
- Екінші ойын нақты аудио шекарасы оқиғасында ашылады. Карточкаларды реттеу, қате/дұрыс жауап және одан кейінгі көріністер тексерілді.
- Аудио ойнату күйі, бір дыбыстың тоқтауы, жаңа көріністің өз басталу уақытынан жалғасуы тексерілді. Бұл тесттерде браузердің медиа API-і үлгіленген; дыбыс физикалық тыңдалған жоқ.
- localStorage арқылы соңғы бөлім, көрініс, аудио уақыты, орындалған ойындар және дыбыс баптаулары сақталатыны тексерілді.
- Энциклопедия мазмұны тек атау мен кері қайту батырмасынан тұратыны тексерілді.
- Бүлінген сақтау деректері қолданбаны тоқтатпайтыны тексерілді.
- Түпнұсқа мәтін көріністерге бөлінгеннен кейін PDF-тен алынған толық мәтінмен автоматты салыстырылды. Тек техникалық жол тасымалдары мен `[thoughtful]` белгісі өңделген.
- Барлық тоғыз көріністің сурет/аудио файлдары бар екені, уақыттардың бір-біріне жалғасатыны және нақты MP3 ұзақтығынан аспайтыны тексерілді.
- Жергілікті HTTP сервері сәтті жауап берді.
- Он төрт автоматты тест сәтті өтті. GitHub Pages үшін `/kanysh/` базалық жолымен бөлек жинау орындалып, шығарылған ресурс жолдары тексерілді.
- Фондық музыканы жеке қосу/өшіру, диктор астында бәсеңдету, ойын кезіндегі кідіріс, музыка деңгейін сақтау, жасырылған беттегі тоқтау және қайта жалғасу тексерілді. Медиа API тесттерде үлгіленген.
- Жасалған жеті иллюстрация файлдары көзбен қаралды; портреттік референс, ортақ стиль, суреттердің оқылуы тексерілді.

## Аудио уақыты

Қосымша тапсырмалар үшін қате жауап, кеңес, пернетақтамен жауап таңдау, сапар бағытын кері қайтару, екі бөлімдегі төрт тапсырманың толық өтуі және мәзірден ашылған ойыннан кейін аудионың сол уақыттан жалғасуы тексерілді.

Бірінші MP3: 238.0016 секунд. Екінші MP3: 269.5314 секунд. Екі файл толық қамтылған. Шекаралар нақты аудионы жергілікті тану нәтижесіндегі сөйлемдердің басталуы мен алдындағы үзілістерге сүйенеді. `audio-manifest.json` ішіндегі шекаралар ойдан алынған жоқ.

Автоматты танудың сөздері қате болуы мүмкін, сондықтан олар кітап мәтініне көшірілген жоқ. Шекаралардың редакторлық дәлдігін тыңдап соңғы рет салыстыру әлі қажет.

## Қалған тексеру шектеулері

Осы сессиядағы браузер басқару құралында қолжетімді браузер болмады. Сондықтан дайын сайттың компьютердегі және нақты телефондағы визуалды көрінісі, сүйреудің нақты браузердегі жұмысы, физикалық аудио шығуы және браузердің autoplay рұқсаты көзбен/құлақпен тексерілген жоқ. CSS ішінде 760 және 370 пиксельге арналған бейімделу, бір бағанды телефон көрінісі, дыбыс деңгейі және азайтылған қозғалыс қолдауы бар.

GitHub аккаунты/репозиторийі қосылмаған. Workflow дайын, бірақ қашықтағы жариялау орындалған жоқ. GitHub Actions-тағы нақты орындалу мен жарияланған URL әлі расталмаған.
