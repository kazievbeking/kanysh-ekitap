# Үш бөлімді біріктіру

Мен 284–285-беттердегі «Мен болмайын, сен бол!» бөлімін мазмұндағы екінші орынға қостым. Бұрынғы екі бөлімнің тұрақты идентификаторларын өзгертпедім: сілтемелер мен сақталған оқу барысы жұмысын жалғастырады.

Жаңа мәтінді берілген PDF-тен толық алдым, тек тасымалданған сөздерді біріктіріп, артық бос орындарды қалыпқа келтірдім. Бес көрініс жасадым: саяси қысым, тергеу, ауруханадағы өтініш, Мұхтарды қорғау және Әуезовтің Мәскеуге жетуі. Үшінші MP3-ті өзгеріссіз пайдаландым; сөйлемдер арасындағы үзілістер бойынша 0 / 63,78 / 105,23 / 168,76 / 190 / 274,442438 секунд шекараларын белгіледім.

Аурухана мен әуежай үшін екі көркем иллюстрация әзірледім. Оларды деректі фотосурет ретінде ұсынбаймын. Мәтіндегі «болуы мүмкін», «сияқты», «деп айтылады» деген белгісіздік тұжырымдарын сақтадым. «Қаныштың өтінішін түсін» тапсырмасын қосып, үзіндіні жаңа бөліммен байланыстырдым. Бұрынғы тапсырмалар да бөлім нөмірімен емес, тұрақты идентификатормен байланысады.

Алдыңғы екі бөлімдегі жергілікті анимация толықтырулары мен толық кадр қатесін түзету осы жарияланымға бірге енгізілді. Генерацияланған бейнероликтер қолданылған жоқ.
